## 🎯 Focus

- **Agent governance.** Multi-agent systems where policy, audit, and access control are part of the architecture, not add-ons.
- **Civic and security tooling.** Transparency platforms, RF observability, OSINT, and adversarial-AI testing.
- **Local-first infrastructure.** Systems that run on hardware the operator owns, built on open-source components with cryptographic auditability.

## 🧭 Engineering principles

1. **Governance is structural.** Enforcement lives in the architecture rather than in a wrapper added later.
2. **Local-first, sovereignty-first.** Prefer systems the operator fully controls. Cloud services are optional, never required.
3. **Failures are data.** Results, including failed attempts, are documented as evidence.
4. **Independent and self-funded.** All work is self-directed.
