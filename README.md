## Principles

1. **Compliance is architectural** — gates and audit trails are structure, not policy docs bolted on later.
2. **Failures are data** — broken builds and closed experiments stay visible so the next design improves.
3. **Self-funded, public by default** — infrastructure intended to be inspected, forked, and challenged.
4. **Evidence over labels** — status on this page tracks releases, demos, and docs, not marketing tiers.
